NONG TRAI MO UOC - GOI PWA
1. Giai nen ZIP.
2. Tai tat ca cac file trong thu muc len thu muc goc (root) cua GitHub repository.
3. Bat GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Mo dia chi HTTPS GitHub Pages de thu game.
5. Day la goi PWA, KHONG phai file APK. Can dong goi them bang dich vu nhu PWABuilder.
